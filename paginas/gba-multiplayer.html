Multiplayer entre computadores

O modo Online beta conecta jogadores em dispositivos diferentes. A tela dividida local é apenas um recurso separado do emulador; para jogar pela internet, use o menu Online beta.

CARREGAR SEM SALVAR NO COMPUTADOR

Iniciar jogo por link

Informe um endereço direto para um arquivo .gba. O navegador busca a ROM e a carrega na memória; ela não é salva como download no seu computador.

O link precisa apontar diretamente para o arquivo .gba e permitir CORS. Links de páginas do GitHub não funcionam; use o endereço do arquivo bruto (raw) se o repositório permitir.

COMO COMEÇAR

Jogar em computadores diferentes

Use o modo Online beta para criar uma sessão e compartilhar o convite com outra pessoa.

01
Carregue uma ROM

O anfitrião carrega o jogo. Você pode selecionar um arquivo local ou informar um link direto para um arquivo .gba na área abaixo.

02
Ative dois jogadores

Para jogar em computadores diferentes, não selecione duas instâncias locais. Abra Online beta e escolha Host Online Session.

03
Teste o Link Cable local

O anfitrião mantém o jogo aberto. O convidado acessa o endereço de convite e entra na sessão pelo próprio navegador.

04
Convide seu amigo

Abra o emulador em nova aba, entre em Online beta → Host Online Session e compartilhe o convite gerado. O recurso é beta e pode apresentar atraso ou falhas de conexão.

INFORMAÇÕES IMPORTANTES

Antes de jogar

Arquivo do jogo

O anfitrião precisa carregar uma ROM. O convidado da sessão online não precisa baixar uma segunda cópia para entrar no modo de transmissão/controle remoto.

Multiplayer online beta

O anfitrião executa a emulação e compartilha a sessão; os convidados recebem a transmissão e enviam seus comandos. O recurso ainda está em testes.

Projeto externo

O emulador é carregado do GitHub Pages do projeto original. É necessário estar conectado à internet para abrir esta página.
